# spider-paint · Help

Powered by **3Draft**. The `spider-paint` and `3Draft` repositories remain independent projects.


A minimal 3D scene builder. Fly through a scene, build with solid prisms, and edit them like a woodworker: saw, move, scale, extrude. This help is the `help/` folder: one markdown file a section, listed here; edit a file and the panel follows.
